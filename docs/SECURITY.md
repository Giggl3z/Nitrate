# Security

## Token safety

`config.json` contains sensitive credentials.

Rules:
- Never commit `config.json`
- Never share token in screenshots, logs, issues, or chats
- Rotate token immediately if exposed

## Repository hygiene

- `config.json` is gitignored
- Use `config.example.json` for safe sharing

## Reporting security concerns

Open a private channel if possible before publishing details publicly.
